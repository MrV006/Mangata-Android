# 🌌 پلتفرم هوشمند مانهواخوان مانگاتا (Mangata)

سیستم فوق تخصصی و مدرن موبایل و وب برای تیم‌های ترجمه، طراحی، و خوانندگان مانهوا، مانها و مانگا. این پروژه به صورت کاملاً زنده، واقعی و بدون شبیه‌سازی با بانک اطلاعاتی دیتابیس `mrvir111_mangata_db` بر روی دامنه `mr-v.ir` متصل گردیده است.

  - **مسدودکننده اجباری زنده اپلیکیشن اندروید (Forced Android App Dialog Blockers):** کنترل ۱۰۰٪ نسخه و پرچم فعالساز آپدیت در شروع لود اپلیکیشن؛ در صورت اعمال از سمت ادمین، کادر هشدار مسدودکننده (AlertDialog) همراه با متن خطای ترجمه شده مدیریت کل نمایان شده و کاربر تا زمانی‌که دکمه مستقیم دانلود را نزده و به آدرس انتقال نیابد قادر به استفاده از اپلیکیشن نخواهد بود. (ادمین کل به صورت خودکار جهت نظارت مستقیم از این قفل مسدودکننده معاف می‌باشد).
