# 🌌 پلتفرم هوشمند مانهواخوان مانگاتا (Mangata)

سیستم فوق تخصصی و مدرن موبایل و وب برای تیم‌های ترجمه، طراحی، و خوانندگان مانهوا، مانها و مانگا. این پروژه به صورت کاملاً زنده، واقعی و بدون شبیه‌سازی با بانک اطلاعاتی دیتابیس `mrvir111_mangata_db` بر روی دامنه `mr-v.ir` متصل گردیده است.

## 📋 لیست کارهای انجام شده (Done)

- [x] **توسعه مجدد و بازنویسی زیرساخت Gradle پروژه اندروید:** پیکربندی کامل `settings.gradle.kts`، `build.gradle.kts` اصلی و فرعی بدون خطای کامپایل.
- [x] **حل مشکل ورود تکراری و پرش حساب پس از پاک کردن کَش (Clear Cache):** انتقال کامل مکانیزم احراز هویت به وب‌سایت وردپرسی. اکنون فرآیند ثبت‌نام کاربر و ورود با مشخصات دیتابیسِ واقعیِ وب‌سایت هماهنگ است و حساب در خارج از اپلیکیشن نیز امن است.
- [x] **برقراری ارتباط مستقیم با REST API وردپرس:** بازنویسی ردیاب‌های Retrofit جهت اتصال مستقیم به پنل وردپرسی در آدرس اصلی `https://mr-v.ir/wp-json/mangata/v1/`.
- [x] **ایجاد تم اختصاصی وردپرس مانگاتا:** پیاده‌سازی کامل هسته PHP قالب با قابلیت لود جداول دیتابیس، آپلود زیپ در رسانه وردپرس، دریافت فایل پاسخ آزمون به منظور پیگیری واقعی امور ترجمه و ریدر وبلاگ.
- [x] **سیستم آپلود زیپ و استخراج خودکار مانهوا در سرور:** پیاده‌سازی متد `uploadChapterZip` در اپلیکیشن و اکشن‌های استخراج مستقیم فایل زیپ در PHP. سرور تصاویر داخل فایل زیپ را استخراج کرده، آنها را به صورت مرتب‌شده سورت می‌کند و به صورت ریدر وب‌تون با عرض کامل ارائه می‌دهد.
- [x] **پنل تصحیح و نمره‌دهی آزمون‌های استخدامی کادر توسط مدیریت کل (Super Admin):** طراحی پنل استقرار آزمون با قابلیت ثبت نمره (0 تا 100) و تغییر وضعیت کارآموز (قبولی یا رد) از طرف مدیریت کل به صورت آنلاین با تأثیر زنده در دیتابیس.
- [x] **تخصیص پویا و مدیریت هوشمند اعضای تیم ترجمه:** امکان تخصیص مترجم، ادیتور و کلینر به مانهواهای مختلف بر حسب نقش در سایت و مدیریت وظایف هر چپتر.
- [x] **برطرف کردن جامع باگ‌های کامپایل و همگام‌سازی Layout ها:** اصلاح تمام خطاهای سینتکس بُعدهای صفحه (`.dp` ها) و اصلاح المان‌های رابط کاربری Jetpack Compose به همراه بهبود کتابخانه‌های به کارگیری تصاویر.
- [x] **حل باگ کرش دیتابیس محلی (Room Database Crash Fixed):** رفع خطای مهلک اجرا `MangaDatabase_Impl does not exist` با پیکربندی کامل، مدرن و هماهنگ ابزار پردازش سمبل‌های کاتلین (`KSP` به جای `annotationProcessor` یا `KAPT`) جهت خودکارسازی کدهای بانک اطلاعاتی محلی.
- [x] **رفع صددرصدی خطای حیاتی قالب وردپرس (Critical Error Resolved):** حذف شناسه نامعتبر XML در خط اول `functions.php` که باعث به هم ریختگی پاسخ هدرها و سقوط وب‌سایت در سرور می‌گردید. اکنون وب‌سایت کاملاً به صورت سالم و سینک‌شده لود می‌شود.
- [x] **بهینه‌سازی ترافیک اتصال دیتابیس واقعی وردپرس:** بازنویسی تابع راه‌انداز پایگاه داده `mangata_setup_tables` به صورت ذخیره‌سازی وضعیت در `options`، به طوری که درخواست‌های REST API و صفحات وب تحت تأثیر پردازش‌های تکراری و پرهزینه SQL قرار نمی‌گیرند.
- [x] **بازنویسی جدول‌ساز دیتابیس وردپرس به روش امن مستقیم (Fail-Safe Database Creation):** جایگزینی کامل متدهای خطاساز `dbDelta` با الگوریتم نوین بررسی زنده و مستقیم فیلدها و ساختار SQL برای هماهنگی نهایی با بانک اطلاعاتی `mrvir111_mangata_db`.
- [x] **محافظت از وب‌سایت در برابر خطاهای عدم نصب افزونه فشرده‌سازی (ZipArchive Fault Prevention):** افزودن بلاک بازدارنده و ایمن `class_exists('ZipArchive')` جهت جلوگیری از کرش کدهای PHP در سرورهایی که فاقد این کتابخانه هستند.
- [x] **رفع قطعی خطای اتصال وب‌سایت HTTP 400 (Bad Request Network Fix resolved):** بازنویسی مکانیزم استخراج پارامترهای REST API در توابع وردپرس به صورت لایه‌بندی شده، به طوری که درخواست‌های POST/Multipart از اپلیکیشن تحت هیچ انتساب یا Content-Typeی دچار خطای ۴۰۰ یا عدم دریافت شناسه کاربری نمی‌شوند.
- [x] **رفع نهایی ارور موتور سخت‌گیر SQL سرور (MySQL Strict Mode Fix):** اصلاح فیلد متنی `description` در جدول مانهواها (حذف مقدار پیش‌فرض نامعتبر `DEFAULT ''` روی ستون‌های TEXT) و تغییر مقادیر پیش‌فرض زمانی صفر `0000-00-00 00:00:00` به `DEFAULT CURRENT_TIMESTAMP`. این اصلاح مانع از خطای ناکامی ساخت دیتابیس در بسترهای پایگاه‌داده بسیار سخت‌گیر می‌گردد.
